# 카카오페이증권 앱 스크린샷 (프로토타입 배경용)

프로토타입은 실제 카카오페이증권 앱 스크린샷을 **배경(정적 목업)**으로 쓰고,
그 위에 플로팅 버튼(FAB) + Frame 바텀시트를 오버레이한다.

> ⚠️ 자사(카카오페이증권) 화면을 자사 대상 과제에서만 사용. 외부에 실제 기능처럼 공개 배포 금지.

## 저장할 파일 (이 폴더에)

세로 모바일 캡처(폭 ~432px)를 아래 이름으로 저장해주세요:

| 파일명 | 화면 | 데모 용도 |
|---|---|---|
| `home.png` | 증권홈 (증권봇/AI인사이트 보이는 화면) | 진입점, 기존 증권봇 대비 포지셔닝 |
| `stock-detail.png` | 삼성전자 종목상세 (하단 판매/구매 버튼) | ⭐ "이거 사도 돼?" + "영상→내 전략" 무대 |
| `community.png` | 삼성전자 토론방 (목록/글) | 커뮤니티 다리(심리·근거 공유) |
| `account.png` | 내 계좌 | 포트폴리오 맥락(가상 보유 오버레이) |

여러 종목상세 캡처가 있으면 `stock-detail-2.png` 등으로 추가해도 됨.
