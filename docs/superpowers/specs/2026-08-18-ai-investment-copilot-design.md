# AI 투자 코파일럿 — 설계 문서 (Design Spec)

- 작성일: 2026-08-18
- 과제: 카카오페이증권 프로덕트 빌더(시니어) — "AI를 활용해 주식 투자 프로덕트 Prototype 만들기"
- 기한: 안내일로부터 4일
- 산출물: PRD(1~2p) · Prototype(GitHub + URL) · AI 활용 문서

> 이 문서는 브레인스토밍에서 확정된 결정의 단일 원본(source of truth)이다. PRD 딜리버러블과 구현 계획은 이 문서에서 파생한다.

---

## 1. 한 줄 정의

**정보를 '내 판단'으로 바꿔주는 AI 투자 코파일럿** — 2030 초보·감투자자가 남을 따라 하지 않고 스스로, 근거 있게 투자 결정을 내리도록 돕는다.

## 2. 해결하려는 문제

**뿌리 원인: 정보는 넘치는데 스스로 판단하는 법을 모른다.**

뉴스·유튜브·리포트·종토방 등 정보는 홍수처럼 쏟아지지만, 그것을 "그래서 지금 내가 뭘 해야 하나"라는 결정으로 번역해주는 것이 없다. 그 결과 개인은 감이나 남의 말에 기대고, 아래의 실패 패턴으로 손실을 본다. (증상 ← 원인)

- **F1 쏠림** — 테마·한 종목 몰빵(분산 실패)
- **F2 추격매수** — 고점에서 뉴스 보고 뒤늦게 진입(FOMO)
- **F3 레버리지 과신** — 곱버스·3배 ETF 장기보유
- **F4 뇌동매매** — 리딩방·유튜버 추종, 근거 없는 매매
- **F5 손절 실패** — 물타기·존버로 손실 방치(감정)

> 핵심 통찰: 이 실패들은 **정보 부족이 아니라 (a) 판단 프레임 부재 + (b) 감정** 문제다. 정보(위키)로 절반, 멘탈 케어(커뮤니티)로 나머지 절반을 푼다.

MVP는 이 중 **F1·F2·F4**를 우선 타깃으로 한다(서로 물려 있는 전형적 실패 서사: 근거 없이 → 남 따라 → 뜨거운 테마에 → 고점에 몰빵). F3·F5는 로드맵.

## 3. 타겟 고객

- **2030 초보 투자자** + **감으로 투자하는 사람**
- 모바일 네이티브, 유튜브로 투자 학습, 커뮤니티 활동 활발, 소액·잦은 매매
- 카카오페이증권의 결(쉽고 친근한 UX, 행동 넛지)과 정렬

## 4. 해결 원칙 (고정 — 페르소나/기능과 무관하게 항상 지킴)

1. **대신 결정하지 않는다.** "사라/팔아라"가 아니라 **사용자의 판단 + 정보를 결합해 보완**한다. (규제상 투자자문 회피 + "판단력이 안 자란다" 문제까지 해결)
2. **항상 내 포트폴리오 맥락을 근거로** 말한다(내 비중·진입가·성향).
3. **결정과 발행(외부 공유)은 사용자가** 한다. 에이전트는 초안까지만. 자동 매매/자동 게시 없음.

## 5. 에이전트 페르소나

**"팩트로 브리핑하고, 되묻고, 반대편도 보여주는 친근한 투자 선배."**

- 톤: 친근·직설(2030 초보 진입장벽 낮춤, 카카오페이증권 결)
- 행동: ① 내 맥락 기반 팩트 브리핑 + ② 소크라테스식 되묻기("왜 지금 사려고?") + ③ 악마의 변호인(반대편 근거 제시)
- 이 행동 조합이 "정보 + 내 판단 결합" 원칙을 UX로 구현한다(단순 챗봇과의 차별점).

## 6. 프로덕트 3대 기둥

1. **🧭 코파일럿(결정 가드레일)** — 사용자와 대화하는 메인 에이전트. 실패 패턴(F1·F2·F4)을 결정 직전에 짚는다. 서브 능력(리서치/전략/코치)을 오케스트레이션.

> **에이전트 정의:** 이 프로덕트는 챗봇이 아니라 **human-in-the-loop 도구사용 에이전트**다. (a) 도구 사용(KIS 시세·유튜브 자막·지표 계산·커뮤니티 읽기·위키 저장), (b) 다단계 오케스트레이션, (c) 개인 위키 기반 기억/개인화를 갖되, **최종 결정과 외부 발행은 사용자**가 쥔다(완전 자율 자동매매 봇 아님).
>
> **MVP 에이전트 구성:** 단일 코파일럿 에이전트 + 내부 "전략 도구"(영상→기법 추출·신호 계산). 멀티 에이전트(코파일럿↔전략/리서치/코치 분리)는 로드맵.
2. **🧠 개인 LLM 위키** — 사용자가 보고·묻고·판단한 것이 **개인 지식으로 축적**. 쓸수록 (a) 에이전트가 나에게 개인화되고 (b) 내 판단력이 자란다. 개인화 플라이휠 + 데이터 해자.
3. **👥 커뮤니티 다리** — 이미 활성화된 페이증권 커뮤니티에 **에이전트 상호작용을 흘려넣어** 감정 케어 + 근거 공유 문화를 만든다.

## 7. 코어 기능 — "영상 → 내 전략" (유튜브 기법 해부기)

**이 기능이 코어인 이유:** 그 자체가 우리 철학("정보를 내 판단으로")의 가장 날카로운 구현이다.
정보(영상) → 판단 가능한 형태로 추출(기법 규칙화) → 내 맥락에 적용·검증(보완) → 위키 축적.

**플로우:**
1. 유튜브 링크 붙여넣기(여러 개 비교 가능)
2. 에이전트가 자막(transcript) 분석 → 기법을 **규칙으로 추출**(진입·청산·근거 지표)
3. **내 관심종목/보유종목에 적용** → 현재 신호 판정(KIS 시세로 지표 계산)
4. **가정·한계 검증** — "이 기법이 안 통하는 상황"을 함께 제시(악마의 변호인 원칙 → 맹목 복사 방지)
5. **기법 카드로 저장** — 개인 위키에 축적·재사용

**MVP 고정 레퍼런스 영상:** "이동평균선 딱 두 개로 완성시킨 평생 써먹는 초간단 매매법" (5일선/20일선)
- URL: https://www.youtube.com/watch?v=bARF75QgOtM
- 선정 이유: 규칙이 기계적(5일/20일선 정배열·이탈)이라 KIS 데이터로 신호 계산 가능, 대중적, "초간단"이라 2030 초보 타겟과 정렬.
- 데모 시나리오: 링크 → 5/20 이동평균선 규칙 추출 → 삼성전자(또는 관심종목)에 현재 신호 판정 → 횡보장 한계 경고 → 기법 카드 저장.
- 리스크: 자막 미제공/추출 실패 시 대체안 필요(영상 설명·수동 입력 폴백, 또는 규칙 프리셋).

## 8. 커뮤니티 다리 (라이트) + 활성화

**양방향 파이프 (에이전트가 읽기/쓰기 다리):**
- 커뮤니티 → 에이전트(읽기): 종목 커뮤니티 심리·논쟁을 **3줄 요약 + 과열도 카드**로, 내 포트폴리오 기준 개인화 해석.
- 에이전트 → 커뮤니티(쓰기): 대화에서 정리된 **판단 근거를 사용자가 한 탭으로 발행**(자랑X, 근거 중심, 익명 가능). **에이전트가 자동 발행하지 않음** — 발행은 사용자 트리거·확인.

**멘탈 케어(문제의 나머지 절반):**
- 패닉셀 순간 → "지금 이 종목 보유자 공포 71%, 너만 그런 거 아냐" + 내 위키의 매수 이유 다시 보기 → 감정 진정.

**활성화(이미 활성 커뮤니티 전제 → 콜드스타트 아님):**
- 핵심 엔진: **AI 대필**(내 위키/매매로 공유글 초안 자동 생성 → "쓸 말 없음" 장벽 제거) + **근거 단위 공유**(수익 자랑 아닌 판단 근거, 손실도 "이렇게 배움" → 부끄럼 제거) + **동질감 매칭**("같은 종목 물린 사람 320명").
- 보조: **도움 평판**(리액션 = '덕분에 다시 생각함' → 건강한 문화 유지) · **급락장 케어 루프**(위기 = 활성화 순간).

## 9. 아키텍처

**진입점(채널):**
- **메인 — 페이증권 앱 내 플로팅 버튼(FAB) → 바텀시트 코파일럿.** 어느 화면에서든 한 탭으로 부르며, **부르는 순간 지금 보던 화면 맥락(예: 종목=에코프로)을 인지**한다. "내 맥락 근거"가 포트폴리오 + 현재 화면까지 확장.
- **보완 — 카카오톡 채널.** 앱 밖에서 에이전트가 먼저 말 거는 push(급락 알림·습관). MVP는 개념/로드맵.

```
[페이증권 앱 화면] ── 우하단 플로팅 버튼(🧭) ── 탭 ──▶ 바텀시트로 등장(화면 맥락 인지)
        │
🧭 AI 투자 코파일럿 (메인 에이전트, 페르소나)
   ├─ 의도 파악 · 내 맥락(포트폴리오/위키) 보유
   └─ 필요 시 서브 능력 호출 후 종합
        │  호출
   ┌────┼─────────────┐
③리서치   ②전략(영상→기법)  ④코치(로드맵)
        │  공통 데이터
증권 오픈 API(KIS: 시세·계좌/주문) · 커뮤니티 · 뉴스/공시
```

- MVP에서 실동작하는 서브 능력은 **②전략(영상→내 전략)** 이 중심. 리서치/코치는 로드맵.

## 10. MVP 스코프 (4일)

**✅ 실제 동작 (코어)**
- ① "영상 → 내 전략" 전체 플로우(고정 레퍼런스 영상 기준)
- ② 코파일럿 채팅(친근한 선배 페르소나) — "이거 사도 돼?"에 실시간 시세 + 내 맥락 근거로 응답
- ③ 실시간 시세/보유 — KIS API 실연동

**UI 방식 (진입점):**
- **페이증권 앱 화면 = 실제 스크린샷을 배경으로 사용**(사용자가 제공: 종목 상세 우선, 커뮤니티 보조). 그 위에 **플로팅 버튼(FAB) + 바텀시트 코파일럿을 오버레이**.
- 배경(앱 셸)은 정적 목업, 그 위의 **코파일럿 대화 + "영상→내 전략"은 실제 동작**. 데모에선 스크린샷별로 화면 맥락(종목)을 매핑.
- 스크린샷은 자사(카카오페이증권) 화면을 자사 대상 과제에서만 사용 — 외부에 실제 기능인 것처럼 공개 배포하지 않는다.

**🟡 라이트 / 목업**
- 개인 위키 — '기법/종목 카드' 저장·조회만(풀 위키 아님, 기술 난도 통제)
- 커뮤니티 다리 — 심리 카드 + '근거 공유' 버튼 목업
- 카카오톡 채널 — 개념/로드맵(실연동 없음)

**🔮 로드맵 (PRD에만 기술, 구현 X)**
- 전략 백테스트·모의 자동주문 · 커뮤니티 풀 구축 · 코치 에이전트(행동교정) · 카톡 실연동 · 개인화 심화 · 리서치 에이전트

## 11. 기술 스택 & 산출물

- 프론트: **Next.js**(웹챗, 카톡 스타일) — 배포하여 Prototype URL 제공
- 시세/계좌: **한국투자증권 KIS Developers API**(무료, REST/웹소켓, 모의투자). *카카오페이증권은 외부 개발자용 공개 트레이딩 API가 없어 공개 오픈API로 실데이터 연동.*
- LLM: **Claude API**(페르소나 대화 · 영상 기법 추출 · 요약)
- 유튜브: 자막(transcript) 추출 → LLM 요약/규칙화
- 저장소: GitHub `https://github.com/lenell0912/roen-assignment.git`

**보안 원칙:** KIS 앱키/시크릿, Claude API 키는 사용자가 직접 발급해 `.env`에 넣는다. 코드는 환경변수에서만 읽으며, 어떤 키도 문서/코드/대화에 하드코딩하지 않는다.

## 12. 가설 & 검증 지표 (PRD용)

**가설**
- H1. 정보를 "내 맥락 + 판단 프레임"으로 번역해주면, 근거 있는 결정이 늘고 뇌동/추격매수가 준다.
- H2. 유튜브 기법을 "추출→적용→한계검증"으로 구조화하면, 초보도 맹목 추종 대신 스스로 판단한다.
- H3. 대화 산출물(근거)을 커뮤니티로 흘려보내면 감정 케어 + 근거 공유가 리텐션을 만든다.

**검증 지표(초안)**
- 북극성(NSM) 후보: **"근거를 동반한 매매 결정 수"**(코파일럿을 거친 결정 비율)
- 활성화: "영상→내 전략" 완료율, 코파일럿 첫 대화 도달률
- 판단 품질: 매매 전 상담 비율, 상담 후 **결정 보류/변경 비율**(뇌동 차단 신호)
- 리텐션/축적: 위키 카드 누적 수, WAU/주간 재방문
- 커뮤니티: 근거 공유 수, '도움됐어' 리액션 수
- 정성: "혼자보다 나은 결정을 했다" 인식(설문/NPS)

## 13. 리스크 & 고려사항

- **규제:** 대신 결정하지 않는 '보완' 원칙으로 투자자문 리스크 회피. 면책 고지 포함.
- **저작권/ToS:** 유튜브 자막 요약은 프로토타입 범위. 상용화 시 정책 검토 필요(문서에 명시).
- **자막 미제공:** 폴백(설명 기반/수동 입력/규칙 프리셋) 준비.
- **KIS 레이트리밋/모의투자 제약:** 시세 위주로 구성, 주문은 모의 또는 시뮬레이션.
- **완성도 vs 과정:** 과제는 완성도보다 문제 정의·해결 방식·구현 과정을 평가 → 문서화(AI 활용 포함)를 산출물로 명시.

## 14. 로드맵 (PRD용)

- **Phase 1 (4일 MVP):** 코파일럿 + 영상→내 전략 + KIS 실시세 (실동작)
- **Phase 2:** 전략 에이전트 확장(백테스트·모의 자동주문), 커뮤니티 근거공유 실동작
- **Phase 3:** 코치 에이전트(행동교정), 다중 에이전트 협업, 카톡 실연동, 개인화 심화
